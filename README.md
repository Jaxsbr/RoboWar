# Robo War

[Play Robo War](https://jaxsbr.github.io/RoboWar/)

## Description

Avoid the enemies, keep shooting, collect power ups.

## Controls

- W - forward
- A - rotate left
- D - rotate right
- Mouse - Aim
- Left Mouse - Shoot
- Esc - Pause
 
## About

This game was made with real effort, as a novice coder I spent countless our figuring out math and techniques for making this work.
Many years later and most of the code can be considered garbage and can be re writen by AI in an eye wink, however it is special to me.

## History

The game started as an ASP.Net web application around 2015.
I had a backend and was able to keep players scores.

In 2018 I decided to port it to a stand-along JavaScript game that could be hosted in Github pages.
Once it was stable and had some bug fixes and fun tweaks I left it in place for 5 years.

In 2023 I made some basic tweaks that improved the enjoyability of the game

In 2026 I'm updating the Readme as a reminder, this is a special project. I will keep it alive.
